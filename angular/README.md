# Angular Interview Notes

A focused, interview-oriented collection of Angular notes covering the core concepts you'll be asked about most often. Each topic follows the same structure — definition, simple explanation, why it's used, key points, syntax, examples, a real-world use case, 5 interview Q&As, common mistakes, and advanced notes.

All examples use **modern Angular** (standalone components, signals, functional guards/interceptors, and the new control-flow blocks).
