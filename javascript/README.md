# JavaScript Interview Notes

A curated set of interview-prep notes covering core JavaScript concepts. Each topic follows the same structure — definition, plain explanation, why it's used, key points, syntax, a runnable example, real-world use cases, 5 interview Q&As, common mistakes, and advanced notes.

Use these for quick revision before interviews or as a learning path from beginner to advanced. Topic files are numbered (`1.variables.md` … `24.shallow-vs-deep-copy.md`) — start at **1** and work upward.

## Suggested Learning Path

1. **Fundamentals:** Variables → Data Types → Objects → Array Methods
2. **Functions & scope:** Scope → Hoisting → Execution Context → Closures
3. **Functional JS:** Higher Order Functions → Map/Filter/Reduce → Currying → Call/Apply/Bind
4. **Async JS:** Callback → Promise → Async/Await → Event Loop → Microtask & Macrotask Queue
5. **OOP & runtime:** this Keyword → Prototype
6. **Browser & performance:** DOM → Debouncing → Throttling → Shallow vs Deep Copy → Memory Leak
