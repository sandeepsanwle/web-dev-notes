Use these for quick revision before interviews or as a learning path from beginner to advanced.

## Suggested Learning Path

1. **Fundamentals:** Variables → Data Types → Objects → Array Methods
2. **Functions & scope:** Scope → Hoisting → Execution Context → Closures
3. **Functional JS:** Higher Order Functions → Map/Filter/Reduce → Currying → Call/Apply/Bind
4. **Async JS:** Callback → Promise → Async/Await → Event Loop
5. **OOP & runtime:** this Keyword → Prototype
6. **Browser & performance:** DOM → Debouncing → Throttling → Shallow vs Deep Copy → Memory Leak
