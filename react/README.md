# React Interview-Prep Notes

A focused, interview-oriented set of notes on core **React** concepts. Each topic follows the same 10-section structure — definition, plain-English explanation, why it's used, key points, syntax, a practical example, a real-world use case, exactly 5 interview Q&A, common mistakes, and advanced notes.

All examples use **modern React** (function components + Hooks) and clean, GitHub-flavored markdown.

## Suggested Learning Path

1. **Fundamentals:** JSX → Components → Props → State
2. **Hooks:** Hooks → useEffect → useMemo → useCallback
3. **State sharing:** Context API → Redux Basics
4. **Under the hood:** Lifecycle → Virtual DOM → Reconciliation
5. **Apps at scale:** Routing → Performance Optimization → Lazy Loading → Error Boundary → Controlled Components
