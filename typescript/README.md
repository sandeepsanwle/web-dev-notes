# TypeScript Interview Notes

Concise, interview-oriented notes on core TypeScript concepts. Topic files are numbered (`1.types.md` … `13.advanced-types.md`) — start at **1** and work upward. Each topic follows the same structure — definition, simple explanation, why it is used, key points, syntax, examples, real-world use cases, 5 interview Q&A, common mistakes, and advanced notes — so they are easy to skim before an interview.

## How to Use

- **New to TypeScript?** Start with the 🟢 Beginner topics: Types, Interface, Type Alias, Type Inference, Enum.
- **Comfortable with basics?** Move to the 🟡 Intermediate topics: Generics, Tuple, Union, Intersection, Utility Types, Type Assertion.
- **Going deep?** Finish with the 🔴 Advanced topics: Decorators and Advanced Types.
